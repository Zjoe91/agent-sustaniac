# Agent Sustaniac — AI Sustainability Roadmap Generator

Agent Sustaniac is an intelligent multi-agent system designed to help organizations quickly generate tailored sustainability roadmaps using AI agents. Built using the Google AI Developer Kit (ADK) and powered by Gemini models, the system automates the process of analyzing a company's profile and mapping out actionable short-, medium-, and long-term goals.

## 🤖 System Architecture
The system consists of four specialized, autonomous agents working together:
*   **Intake Agent:** Parses raw human descriptions into structured company profiles.
*   **Research Agent:** Analyzes industry trends, regulatory environments, and sustainability challenges.
*   **Strategy Agent:** Synthesizes profiles and research into a concrete 3-year sustainability roadmap.
*   **Reporting Agent:** Generates a polished, human-readable final report.

## 🚀 Key Features
*   Multi-turn interactions and complex expert agent workflows.
*   Tool integration including custom KPIs and emissions estimation techniques.
*   Includes a complete architectural diagram and reproducible code.

## 🛠️ How to Use
1. Open the `agent-sustaniac.ipynb` notebook.
2. Ensure your Google AI Studio API key is configured.
3. Run the cells sequentially to simulate the multi-agent planning workload.
